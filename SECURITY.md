# Security Policy

This is a maker-focused hardware project and does not currently have a formal private security disclosure program.

## Reporting A Security Concern

If you believe you found a security-relevant issue:

1. Do not publish exploit details immediately.
2. Open a GitHub issue only if the details are safe to discuss in public.
3. Otherwise contact the maintainer through a private channel if one is available from the repository profile.

## Scope

The most relevant concerns for this project are likely to involve:

- unsafe default behavior in helper tooling
- accidental exposure of local credentials or local network details
- insecure documentation that encourages unsafe deployment patterns

There is no warranty that this project is suitable for safety-critical or security-critical use.
